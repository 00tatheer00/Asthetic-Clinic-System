# Production Environment Configuration Guide

**Project**: Brimish Skin Care Clinic Management & Public Platform  
**Target Hosting**: Vercel (Next.js 16) + Supabase + Resend  
**Version**: 1.0.0-production  
**Date**: October 2026

---

## 1. Environment Variables Architecture

Next.js App Router enforces strict isolation between client-side code and server-side code:
- Variables prefixed with `NEXT_PUBLIC_` are bundled into client-side JavaScript and accessible in the browser.
- Variables **without** `NEXT_PUBLIC_` are strictly isolated to Node.js server runtimes (Server Components, Server Actions, Route Handlers).

> [!CAUTION]
> **Service Role Security Rule**: `SUPABASE_SERVICE_ROLE_KEY` bypasses all Row-Level Security policies. It MUST NEVER be prefixed with `NEXT_PUBLIC_` or imported into any client component (`'use client'`).

## 2. Complete Environment Variables Matrix

| Variable Name | Scope | Security Classification | Purpose / Usage | Example / Format |
|---|---|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Public (Client + Server) | **Public** | Supabase REST/Auth API gateway URL. | `https://xxxx.supabase.co` |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Public (Client + Server) | **Public** | Supabase Anonymous public key. Enforces RLS on every database request. | `eyJhbGciOiJIUzI1NiIsInR5cCI6...` |
| `SUPABASE_SERVICE_ROLE_KEY` | Server-Only | **SECRET** | Master administrative key for guest checkouts, public appointments, and system tasks. | `eyJhbGciOiJIUzI1NiIsInR5cCI6...` |
| `RESEND_API_KEY` | Server-Only | **SECRET** | API authentication key for Resend email dispatch. | `re_1234567890abcdef...` |
| `RESEND_FROM_EMAIL` | Server-Only | **Config** | RFC 5322 compliant sender email. Domain must be verified with DKIM/SPF in Resend. | `Brimish Skin Care <noreply@brimishskincare.com>` |
| `CLINIC_ADMIN_EMAIL` | Server-Only | **Config** | Recipient email for internal clinic alerts (new appointment request, low stock notification). | `admin@brimishskincare.com` |
| `NEXT_PUBLIC_SITE_URL` | Public (Client + Server) | **Public** | Canonical URL for sitemaps, OpenGraph metadata, and email action links. | `https://brimishskincare.com` |
| `CRON_SECRET` | Server-Only | **SECRET** | High-entropy token required in `Authorization: Bearer <token>` for `/api/cron/*`. | `64-character-hex-or-uuid` |

## 3. Environment Specific Setup

### 3.1 Local Development (`.env.local`)
Create `.env.local` inside the `brimish-skincare/` project root. This file is git-ignored and should only contain development credentials.

```bash
# Supabase Local or Dev Project
NEXT_PUBLIC_SUPABASE_URL=https://your-dev-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-dev-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-dev-service-role-key

# Resend Test Key
RESEND_API_KEY=re_dev_key

# Email Config
RESEND_FROM_EMAIL=Brimish Dev <onboarding@resend.dev>
CLINIC_ADMIN_EMAIL=your-personal-email@domain.com

# Site URL
NEXT_PUBLIC_SITE_URL=http://localhost:3000

# Cron
CRON_SECRET=local-dev-cron-secret-2026
```

### 3.2 Vercel Production Deployment
Configure environment variables in the **Vercel Dashboard** under:  
**Settings → Environment Variables**

Ensure the following checkboxes are enabled for each environment:

1. **Production**:
   - `NEXT_PUBLIC_SUPABASE_URL`: Production Supabase project URL.
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`: Production Supabase anon key.
   - `SUPABASE_SERVICE_ROLE_KEY`: Production service role key.
   - `RESEND_API_KEY`: Production Resend API key.
   - `RESEND_FROM_EMAIL`: `Brimish Skin Care <noreply@brimishskincare.com>`.
   - `CLINIC_ADMIN_EMAIL`: Official clinic operational email (e.g. `drbrimish@brimishskincare.com`).
   - `NEXT_PUBLIC_SITE_URL`: `https://brimishskincare.com`.
   - `CRON_SECRET`: Generate a secure random token (e.g. `openssl rand -hex 32`).

2. **Preview / Staging**:
   - Duplicate production keys or point to a dedicated Supabase staging project.

## 4. Key Verification & Testing Checklist

- [ ] `NEXT_PUBLIC_SUPABASE_URL` starts with `https://` and has no trailing slash.
- [ ] `NEXT_PUBLIC_SITE_URL` matches the production domain (e.g. `https://brimishskincare.com`).
- [ ] `SUPABASE_SERVICE_ROLE_KEY` is never referenced in any file starting with `'use client'`.
- [ ] Resend domain `brimishskincare.com` has active DNS records:
  - SPF: `v=spf1 include:amazonses.com ~all`
  - DKIM: 3 CNAME records generated by Resend
  - DMARC: `v=DMARC1; p=none; rua=mailto:...`
- [ ] Vercel Cron configured in `vercel.json` with the matching `CRON_SECRET`.
